<Tip>
If you only want your Pearl on a Twilio number, you don't need this page: [Twilio Integration](/pages/twilio_integration) connects your Twilio numbers with no code.
</Tip>

Use a bridge when your own code must stay in the middle of the phone call: to run your own IVR or routing before the Pearl answers, to record or analyse the audio yourself, or to decide per call which Pearl takes it.

Twilio [Media Streams](https://www.twilio.com/docs/voice/media-streams) and the Pearl speak the same audio: 8 kHz μ-law in 20 ms frames. Twilio wraps each frame in base64 JSON, the Pearl takes raw bytes, so the bridge only converts between the two, with no transcoding and no added delay.

## The bridge

Node.js 18 or later: `npm install express ws twilio`. The server must be reachable by Twilio over `https` and `wss`; in development, a tunnel such as ngrok works.

```javascript bridge.mjs
// bridge.mjs: Twilio calls stream to this server, which connects each one to the Pearl over a WebSocket.
import express from "express";
import twilio from "twilio";
import { WebSocketServer, WebSocket } from "ws";

const PEARL_API = `https://api.nlpearl.ai/v2/Pearl/${process.env.NLPEARL_PEARL_ID}/WebSocket`;
const twilioClient = twilio(process.env.TWILIO_ACCOUNT_SID, process.env.TWILIO_AUTH_TOKEN);

const app = express();
app.use(express.urlencoded({ extended: false }));

// 1. Your Twilio number's voice webhook: stream the call to this server, with the caller's number
app.post("/twilio/voice", (req, res) => {
  res.type("text/xml").send(`<Response>
  <Connect>
    <Stream url="wss://${req.headers.host}/twilio/stream">
      <Parameter name="from" value="${req.body.From}" />
    </Stream>
  </Connect>
</Response>`);
});

const server = app.listen(8080);
const streams = new WebSocketServer({ server, path: "/twilio/stream" });

streams.on("connection", (twilioWs) => {
  let pearl;
  let ready = false;
  let streamSid;
  let callSid;

  twilioWs.on("message", async (data) => {
    const message = JSON.parse(data);

    if (message.event === "start") {
      ({ streamSid, callSid } = message.start);

      // 2. Create the Pearl's call, in Twilio's own format, with the caller's number as the end user
      const response = await fetch(PEARL_API, {
        method: "POST",
        headers: { Authorization: `Bearer ${process.env.NLPEARL_API_KEY}`, "Content-Type": "application/json" },
        body: JSON.stringify({ endUserId: message.start.customParameters.from, audioFormat: "ulaw_8000" }),
      });
      if (!response.ok) {
        console.error("create failed", response.status, await response.text());
        await twilioClient.calls(callSid).update({ status: "completed" });
        return;
      }
      const call = await response.json();
      pearl = new WebSocket(`${call.url}?ticket=${call.ticket}`);
      pearl.on("close", () => { ready = false; });

      pearl.on("message", async (frame, isBinary) => {
        if (isBinary) {
          // 3a. The Pearl's voice to the caller: the same μ-law bytes, in base64 for Twilio
          twilioWs.send(JSON.stringify({ event: "media", streamSid, media: { payload: frame.toString("base64") } }));
          return;
        }
        const event = JSON.parse(frame.toString());
        if (event.type === "ready") {
          ready = true;
        } else if (event.type === "transfer") {
          // 4. The flow transferred: dial its target on the same phone call
          await twilioClient.calls(callSid).update({ twiml: `<Response><Dial>${event.target}</Dial></Response>` });
        } else if (event.type === "ended" && !["transfer", "client_hangup"].includes(event.reason)) {
          // 5. The Pearl ended the call: hang up the phone call too
          await twilioClient.calls(callSid).update({ status: "completed" });
        }
      });
    } else if (message.event === "media" && ready) {
      // 3b. The caller to the Pearl: Twilio's base64 μ-law, as raw bytes
      pearl.send(Buffer.from(message.media.payload, "base64"));
    } else if (message.event === "stop" && pearl?.readyState === WebSocket.OPEN) {
      // The caller hung up
      pearl.send(JSON.stringify({ type: "hangup" }));
    }
  });
});
```

## Connect your Twilio number

1. Run the bridge with your NLPearl and Twilio credentials:

   ```bash
   export NLPEARL_API_KEY="<AccountId>:<SecretKey>"
   export NLPEARL_PEARL_ID="<pearlId>"
   export TWILIO_ACCOUNT_SID="AC..."
   export TWILIO_AUTH_TOKEN="..."
   node bridge.mjs
   ```

2. In the Twilio Console, set your number's **A call comes in** webhook to `https://<your-server>/twilio/voice`, method `POST`.
3. Call the number: the Pearl answers.

## How the bridge handles each step

| Step | Twilio | The bridge | The Pearl |
| --- | --- | --- | --- |
| The call starts | `start`, with the caller's number as a custom parameter | Creates the connection with the caller's number as `endUserId` and `audioFormat: "ulaw_8000"` | `ready` |
| The caller speaks | `media`, base64 μ-law | Decodes the base64 and sends the bytes | Hears the caller |
| The Pearl speaks | Plays what it receives | Encodes each frame in base64 as a `media` message | Sends 20 ms frames in real time |
| The flow transfers | Dials the target | Replaces the call's TwiML with `<Dial>` | `transfer`, then `ended` |
| The Pearl hangs up | Ends the call | Completes the call through the Twilio API | `ended` |
| The caller hangs up | `stop` | Sends `hangup` | `ended` (`client_hangup`) |

The Pearl's frames come paced in real time, so the bridge never needs Twilio's `clear` message: when the caller interrupts, the next frames are already silence.

<Note>
- With the caller's number as `endUserId`, the Pearl's memory, the call history and any flow step that uses the phone number work as on a phone call.
- If your transfer targets are SIP addresses, dial them with `<Dial><Sip>` instead of a bare `<Dial>`.
- In production, [validate Twilio's signature](https://www.twilio.com/docs/usage/webhooks/webhooks-security) on `/twilio/voice`.
</Note>
