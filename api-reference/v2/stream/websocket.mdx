The second step of a stream call. [Create Stream Token](/api-reference/v2/stream/create-token) returns the `url` and a `token`: open `url?token=<token>`, for example `wss://agents.nlpearl.ai/Stream/WebSocket?token=wst_...`, within 60 seconds, and the conversation runs on this connection until the call ends.

## Connection

<ParamField query="token" type="string" required>
  The `token` from Create Stream Token, starting with `wst_`. It is single use and valid for 60 seconds. From a server you can send it in the `Authorization: Bearer wst_...` header instead.
</ParamField>

Always open the `url` that Create Stream Token returns rather than a fixed address. No subprotocol is needed.

| Status | Meaning |
| --- | --- |
| `101` | Connected. Pearl sends `ready` at once. |
| `400` | Not a WebSocket upgrade request. |
| `401` | The token is missing, unknown, expired or already used. Create a new token. |
| `410` | The call was ended before anyone connected, for example from the NLPearl platform. Create a new token. |

A browser does not show the status of a refused connection: the socket closes at once with code `1006`.

---

## Send

What your app sends. Audio is binary, everything else is a JSON text message.

### Audio

20 ms of the end user's audio, as a binary message, **every 20 ms for the whole call**. Start after `ready`.

- Raw bytes in the call's [audio format](#audio-formats): 160 bytes in `ulaw_8000`, 960 bytes in `pcm_24000`.
- In `opus_8000` and `opus_24000`, one Opus packet per message: mono, encoded at the call's sample rate. Packets of up to 120 ms are accepted.
- When the end user is quiet or muted, send silence frames, not nothing. On an Opus call, keep encoding silence: turn discontinuous transmission (DTX) off.
- Other raw frame lengths are accepted when they hold whole samples. A message may be up to 16 KB.

### `hangup`

```json
{ "type": "hangup" }
```

Ends the call. Pearl answers with `ended` (`client_hangup`), then closes the connection.

### `ping`

```json
{ "type": "ping", "t": 1730624400123 }
```

Optional. Pearl answers with [`pong`](#pong), which echoes `t`, so you can time the round trip. `t` is any number you choose, such as your clock in milliseconds, and may be left out.

Any message counts as activity for the 60-second `no_audio` timer, so a client that streams audio never needs `ping` to keep the call alive.

Unknown event types, and text that is not a JSON object with a string `type`, are ignored.

## Receive

What Pearl sends: `ready` first, then audio and a `pong` for each of your pings, then at the end an optional `transfer` and one `ended`.

### `ready`

Sent once, right after you connect.

```json
{
  "type": "ready",
  "protocol": 1,
  "callId": "6720f3c1a8b4e5d6f7a8b9c0",
  "audio": { "encoding": "pcm_s16le", "sampleRate": 24000, "channels": 1, "frameMs": 20 }
}
```

<ResponseField name="protocol" type="integer">
  The protocol version: `1`.
</ResponseField>
<ResponseField name="callId" type="string">
  The call's id, as in the Create Stream Token response.
</ResponseField>
<ResponseField name="audio" type="object">
  The format of every binary message, in both directions: the same object as in the Create Stream Token response.
</ResponseField>

### Audio

20 ms of Pearl's voice, as a binary message, **every 20 ms for the whole call**, with silence while it listens. On an Opus call, each message is one 20 ms Opus packet.

- Play the frames through a small jitter buffer of 60 to 100 ms. If it grows past about 300 ms, after a network stall, drop the oldest audio.
- There is no "clear" or interruption event, and you need none: when the end user talks over Pearl, it stops speaking and the next frames are already silence.

### `pong`

The answer to a `ping`, sent between two audio frames, within about 20 ms.

```json
{ "type": "pong", "t": 1730624400123 }
```

<ResponseField name="t" type="number | null">
  The `t` of your `ping`, or `null` when it had none.
</ResponseField>

A `ping` sent before the call's audio starts gets no answer.

### `transfer`

The flow's [Transfer Call](/pages/transfer_call) node transferred the call. It is sent once Pearl has finished its transfer announcement, and is followed at once by `ended` (`transfer`). Carrying the call on, to a person, a queue or a phone number, is up to you.

```json
{
  "type": "transfer",
  "target": "+14155550123",
  "triggerDescription": "The caller asks for a human agent",
  "warmTransferMessage": "Dana is calling about order A-1234",
  "sipHeaders": {},
  "variables": { "firstName": "Dana", "orderId": "A-1234" }
}
```

<ResponseField name="target" type="string">
  The destination set on your Pearl's transfer, as entered: usually a phone number or a SIP address.
</ResponseField>
<ResponseField name="triggerDescription" type="string">
  Why the flow transferred.
</ResponseField>
<ResponseField name="warmTransferMessage" type="string | null">
  The warm-transfer message set for the receiving side.
</ResponseField>
<ResponseField name="sipHeaders" type="object">
  SIP headers, only when the transfer is set to forward them.
</ResponseField>
<ResponseField name="variables" type="object">
  The data Pearl has collected so far, by variable name.
</ResponseField>

### `ended`

The call is over. Pearl then closes the connection with code `1000` and the reason as the close description.

```json
{ "type": "ended", "reason": "agent_hangup", "durationSec": 94 }
```

<ResponseField name="reason" type="string">
  Why the call ended:

  | `reason` | Meaning |
  | --- | --- |
  | `client_hangup` | You sent `hangup`, closed the connection, or it dropped. |
  | `agent_hangup` | Pearl ended the call: end of the flow, its silence handling, and so on. |
  | `operator_hangup` | The call was hung up from the NLPearl platform. |
  | `transfer` | The flow transferred the call, right after `transfer`. |
  | `max_duration` | Your Pearl's maximum call duration was reached. |
  | `no_audio` | No message from you for 60 seconds. |
  | `error` | The call failed on NLPearl's side. |
</ResponseField>
<ResponseField name="durationSec" type="integer">
  Whole seconds the call ran, from connection to end.
</ResponseField>

If you close the connection yourself, or it drops, nothing more arrives: the call is recorded as `client_hangup`.

## Audio formats

`audioFormat`, chosen in Create Stream Token, sets the format of every frame, the same in both directions. The same format has a name in each place it appears:

| `audioFormat` (Create Stream Token) | `audio.encoding` (response and `ready`) | Sample rate | Samples | One 20 ms frame | Silence | `audioQuality` (call history) |
| --- | --- | --- | --- | --- | --- | --- |
| `ulaw_8000` (default) | `mulaw` | 8000 Hz | G.711 μ-law, 8-bit, mono | 160 bytes | `0xFF` bytes | `phone` |
| `pcm_24000` | `pcm_s16le` | 24000 Hz | Signed 16-bit PCM, little-endian, mono | 960 bytes (480 samples) | `0x00` bytes | `hd` |
| `opus_8000` | `opus` | 8000 Hz | Opus, mono | One Opus packet, its size varies | Encoded silence | `phone` |
| `opus_24000` | `opus` | 24000 Hz | Opus, mono | One Opus packet, its size varies | Encoded silence | `hd` |

## Limits

| Item | Limit |
| --- | --- |
| Token | Single use, valid 60 seconds |
| Connections per call | 1 |
| Concurrent calls | Your Pearl's [agents](/pages/agents), shared with its phone calls. One is taken when the token is created. |
| Call duration | Your Pearl's **Max Call Duration**, from 1 to 120 minutes; 30 minutes when it is not set. Reaching it ends the call with `max_duration`. |
| Silence from your side | 60 seconds without any message ends the call with `no_audio` |
| Message size | 16 KB |

## Versioning

`ready.protocol` is `1`. New event types may be added within a version, which is why unknown types are ignored. A change to the frame format would raise the version.

<RequestExample>
```javascript JavaScript
const ws = new WebSocket(`${call.url}?token=${call.token}`);
ws.binaryType = "arraybuffer";

ws.onmessage = (message) => {
  if (typeof message.data !== "string") {
    play(message.data);                      // 20 ms of Pearl's voice
    return;
  }
  const event = JSON.parse(message.data);    // ready, pong, transfer, ended
};

// After ready, every 20 ms: ws.send(frame) with 20 ms of the end user's audio.
// To hang up: ws.send(JSON.stringify({ type: "hangup" }));
```

```python Python
async with websockets.connect(f"{call['url']}?token={call['token']}") as ws:
    ready = json.loads(await ws.recv())      # always the first message
    # every 20 ms: await ws.send(frame) with 20 ms of the end user's audio
    async for message in ws:
        if isinstance(message, bytes):
            play(message)                    # 20 ms of Pearl's voice
        else:
            print(json.loads(message))       # pong, transfer, ended
```
</RequestExample>
